# Code of conduct

One rule, then what it means the first time it is tested.

**Be decent to each other.** Critiques target decisions, not people. This
project argues about ADRs, keymaps and shell colours because those arguments
are the work — sharpen the disagreement, not the person.

**The repository is in English** — code, comments, docs, ADRs, issue titles,
commit messages. One language is not a preference here; it is what keeps the
record readable by every contributor, including the ones who arrive later and
owe nobody a translation.

**When something is wrong** — a discussion turned personal, a contributor
being worn down — open an issue, or contact the maintainer
([@avelino](https://github.com/avelino)) through GitHub. Those are the only
channels that exist, and a report sent nowhere helps nobody. Security reports
go to the maintainer directly, never into a public issue.

**Consequence.** A warning comes first and names the behaviour. Behaviour
that keeps hurting people after the warning ends in removal from the
project's spaces: content deleted, contributor banned. There is no committee
and no version number to appeal to — a maintainer who would rather lose a
patch than a person.
